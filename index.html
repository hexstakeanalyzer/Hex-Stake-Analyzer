About This Tool
What It Does

A fully client-side HEX stake analyzer for both PulseChain (pHEX) and Ethereum (eHEX). Reads your native HEX stakes, HSI (Hedron Staked Instances), and HTT (HEX Time Token) stakes directly from the blockchain on either or both chains, calculates yield, fetches live prices, and renders an interactive dashboard — all in your browser.

Toggle between PulseChain only, Ethereum only, or both chains together. When viewing both, each stake is correctly valued at its own chain's live price — pHEX and eHEX trade independently since the May 2023 fork.

Supports multi-wallet analysis with aggregated and per-wallet/per-chain views, sortable stake tables, cost basis tracking, unrealized + realized P&L with lifetime yield history, effective APY, daily yield rate, T-Share metrics, bridged eHEX detection on PulseChain, and full HTT (HEX Time Token) analysis for Actuator-delegated stakes — including live per-HTT USD prices, extractable / extracted / in-wallet USD values, and automatic discovery of any HTT series (Actuator-listed or otherwise).

Data Sources

Stake Data: Read directly from the HEX contract via public RPCs. PulseChain: 4 nodes with failover (rpc.pulsechain.com et al.). Ethereum: publicnode (primary), with additional candidates tested at runtime. The HEX contract address is identical on both chains; state is independent since the fork.

Live Price: DexScreener API per chain — PulseX DEX for pHEX, Uniswap for eHEX (highest-liquidity pair). Falls back to CoinPaprika, then CoinGecko (hex-pulsechain / hex) per chain if unavailable.

HTT Discovery: Two-layer scan on PulseChain. Primary: probe the Actuator contract's maturityToInfo(day) mapping across a ~27-year horizon so every Actuator-listed HTT is found automatically. Safety net: PulseX v2 subgraph query for any HTT-* token, filtered by a case-sensitive name match to reject spoofs. Result: any HTT that exists on-chain gets picked up without a code change.

Live HTT Prices: PulseX v2 subgraph (graph.pulsechain.com — Uniswap-V2 fork), field Token.derivedUSD. One batched GraphQL call covers every discovered HTT contract; refreshes on the same 60s cadence as the HEX price. A dash means the subgraph has no routed USD price yet for that series (typically thin liquidity for a newer HTT).

Historical Prices: Two-tier resolution. Primary: hardcoded tables generated from HEXDailyStats.com on-chain DEX data (eHEX from Day 1, pHEX from Day 1261). Fallback: any day not in the static table is fetched at runtime from CoinGecko's market_chart/range endpoint (free tier, no key) — covers days published since the last table refresh, and any future scenario where HEXDailyStats becomes unreachable.

T-Share Price: Derived on-chain from each chain's HEX contract globalInfo() shareRate. The two chains have independent share rates since the fork.

Sparkline: CoinGecko 30-day market chart (supplementary, fails silently). Tracks the currently-displayed primary chain.

Security & Privacy

This tool is strictly read-only. No cookies, no backend, no analytics, no tracking. The only network calls are blockchain RPC reads and public price API fetches.

All data lives in browser memory for the duration of your session and is gone when you close the tab. A temporary sessionStorage cache speeds up re-scans within the same tab but is automatically erased when the tab closes. Wallet addresses are never transmitted to any server.

Recent-address history: the last 20 addresses you analyze are saved to localStorage on this device only, so you can jump back to a wallet you've looked at before. Click the address input to open a dropdown showing your saved wallets; click one to add it, click × on a row to drop just that one, or click Clear addresses at the bottom to wipe the whole list. The list is never sent anywhere. On a shared or public computer, click Clear when you're done.

No wallet connection required. No private keys. No signatures. Just paste a public address.

Technical Details

Single-file HTML application. Charts rendered with Chart.js, loaded from CDN.
